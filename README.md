# InvestTrack Configuration Repository

This repository contains centralized configuration for all InvestTrack microservices.

## Configuration Files

- `application.properties` - Common configuration for all services
- `market-service.properties` - Market Service configuration
- `wallet-service.properties` - Wallet Service configuration  
- `gateway-service.properties` - Gateway Service configuration

## Usage

These configurations are read by the Config Server and distributed to microservices at startup.
